Pre-printed form

For offices whose clearance forms are already printed: the app prints only the values, each in its place on the form.

Print clearances on

Paper: Long bond (8.5 × 13 in). Change it in Settings to match your forms.

Where each value goes

Drag a value on the page, or type its distance from the paper’s left and top edges in millimetres. Select a value and use the arrow keys to nudge it (hold Shift for bigger steps).

Left, top and width are in millimetres; size is in points (10 is normal). Values too long for their width print smaller.

Printer adjustment

If every value lands a little off in the same direction, move them all at once instead of one by one.

Use a minus sign to move left or up, e.g. -2.5.
